> :book: In Japanese, "waiwai" (ワイワイ) is an expression used to describe a lively, cheerful atmosphere with people chatting, laughing, or making happy noises together

### <p align="center"> · ♥︎ · </p>

*WaiWai* is a minimal zsh theme that greets you with a cute random emoji each time you open a new terminal session :whale:

## :maracas: Features

:heart_on_fire: **300+** emojis  
:tada: **50+** holidays & special events  
:calendar: Built-in calendar taking all things in hand  
:birthday: Birthday greetings! *(see the theme file)*  
:shamrock: Basic git status display  

## :egg: Requirements

- [Zsh](https://github.com/ohmyzsh/ohmyzsh/wiki/Installing-ZSH)
- [Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh/wiki)

### Optional:
- [kitty](https://sw.kovidgoyal.net/kitty/) (with [bliss](https://github.com/ejohnso49/bliss-kitty-theme) theme :smirk_cat:)
- [Lilex](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/Lilex.zip) font

## :fried_egg: Installation

- Download the [theme file](https://github.com/miamoremustachio/wai/blob/main/waiwai.zsh-theme)
- Put it in your themes directory (`~/.oh-my-zsh/custom/themes`)
- Add this line to the `~/.zshrc`:
```
ZSH_THEME="waiwai"
```
- Restart the terminal
